Este projeto é um sistema simples de controle de estoque desenvolvido em Java para a disciplina de Programação Orientada a Objetos. O sistema permite controlar o estoque de diferentes tipos de peças, como acessórios, roupas de tamanho único e roupas com tamanhos P, M e G.

O programa utiliza conceitos de orientação a objetos, como classe abstrata, herança, sobrescrita de métodos e polimorfismo. A classe Peca serve como base para os produtos, enquanto as classes Acessorio, RoupaTamanhoUnico e RoupaPMG implementam comportamentos específicos de venda e reposição de estoque.

A aplicação principal possui um menu interativo, no qual o usuário pode escolher um produto para realizar uma venda. Após cada venda, o sistema atualiza o estoque e verifica se é necessário fazer a reposição automática com base no estoque mínimo e máximo definidos para cada produto.
